## 三维球面透视投影视角

普通二维圆圈显得呆板的原因在于缺乏空间透视感。小团子的核心视觉技巧在于：**把双眼视作依附在三维球体表面的几何曲面，并投影到二维平面**。

### 椭圆挖孔与变换矩阵

眼睛通过 SVG `<mask id="yeux">` 进行反向裁切，利用 `matrix(a, b, c, d, e, f)` 动态控制双眼的旋转倾角与横向压挤：

```svg
<!-- 左眼与右眼的不同透视压缩矩阵 -->
<path
  d="M-9.3 -11.3A9.3 9.3 0 0 1 0 -20.6L0 -20.6A9.3 9.3 0 0 1 9.3 -11.3L9.3 11.3A9.3 9.3 0 0 1 0 20.6L0 20.6A9.3 9.3 0 0 1 -9.3 11.3Z"
  transform="matrix(0.87,-0.33,0.45,0.84,21.42,-43.32)"
  fill="#000000"
/>
```

当小团子转向右侧时，右眼在透视投影下横向压缩更大（表现为更狭窄的椭圆），而左眼更加展开，营造出真实的球体转动纵深感。

## 状态机与逐帧插值

情绪过渡采用有限状态机（FSM）驱动：

- **关键帧参数化**：将每个情绪状态抽象为一组离散控制参数（左眼中心 $(x_1, y_1)$、右眼中心 $(x_2, y_2)$、瞳孔宽高比、眼睑弯曲度）。
- **非线性缓动**：采用三次贝塞尔曲线（Cubic Bézier）计算参数在时间轴上的变化率，赋予小团子类似液态果冻的弹性质感。
- **动态呼吸扰动**：在待机（`idle`）状态下叠加上下 $5\text{px}$ 的微小正弦波动，赋予静态图形呼吸生命力。
