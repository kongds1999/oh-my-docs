## 动作序列时间轴编排

为了使小团子能表达连贯的故事情节，项目在前端构建了直观的时间轴编排器：

- **动作轨道（Action Tracks）**：用户可以将不同的情绪片段拖拽到时间轴上，定义开始时间与持续帧数。
- **平滑融合（Cross-fading）**：当两个不同状态在时间轴相遇时，插值引擎自动在前后 $300\text{ms}$ 内计算混合过渡状态，避免突兀瞬跳。
- **实时回放与循环**：支持随时预览整组动画，调整全局 FPS 与播放速率。

## 纯前端导出媒体流水线

为了方便开发者将小团子集成到博客、个人主页或社交媒体，项目实现了全浏览器侧的导出机制：

| 导出格式 | 实现原理 | 典型使用场景 |
| :--- | :--- | :--- |
| **纯 SVG 代码** | 序列化当前 DOM 树与 SMIL 动画标签 | 网页轻量矢量徽章 |
| **PNG 序列帧** | Canvas 离屏逐帧栅格化渲染并打包 ZIP | 游戏开发与传统动画贴图 |
| **GIF 动图** | 基于 `gifshot` / `omggif` 在 Web Worker 中压缩编码 | 社交网络表情包与聊天工具 |
| **MP4 视频** | 利用 `MediaRecorder` API 与 H.264 硬件加速编码 | 视频剪辑与演示片头 |
