## 工具调用与智能裁剪

Coding Agent 最常见的性能杀手是庞大的工具输出（如编译报错几千行、`git diff` 几万字符）。本项目实现了细粒度裁剪过滤器：

- **头尾保留 + 中间省略**：默认保留前 50 行与后 20 行，中间标注 `... [省略 N 行] ...`。
- **结构化重定向**：对于超长输出，自动转储为本地临时日志文件，仅将路径与核心结论返回给模型。
- **敏感信息过滤**：内置正则扫描引擎，自动脱敏 API Key、密码与私钥。

## 动态 Skill 装载机制

为了避免在系统 Prompt 中预置过多不常用的指令，项目引入了渐进式 Skill 体系：

- **声明式目录结构**：每个 Skill 包含 `SKILL.md`，定义其适用场景、依赖与可用脚本。
- **按需激活**：模型在初次识别到特定领域任务（如 Docker 配置、数据库迁移）时，通过内部工具动态载入 Skill 内容。
- **版本隔离**：支持局部工作区 Skill 与全局通用 Skill 的分层覆盖。

## 子 Agent（Subagent）协作

针对耗时或高噪音的子任务，主 Agent 可派生轻量子智能体独立执行：

```python
# 派生子 Agent 执行专项检索
search_agent = Agent(
    name="CodeSearchWorker",
    instructions="在指定子目录中深入搜索符号定义与调用链路，返回简洁结论。",
    tools=[grep_tool, find_symbol_tool]
)
```

子 Agent 在独立的沙箱上下文中运行，执行完成后仅将归纳后的精炼结论返回主会话，有效保护主上下文整洁。

---

## Checkpoint 状态持久化与重放

每一次工具执行与用户交互均生成快照记录：

- **原子化 Checkpoint**：记录当前代码变更差异、会话消息队列与环境变量。
- **撤销与回滚（Rollback）**：支持在终端使用快捷命令回滚到上一个安全节点。
- **跨会话持久化**：会话可序列化存储到 SQLite / JSONL 文件，随时恢复与重放。
