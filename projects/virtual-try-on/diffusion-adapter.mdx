## 扩散模型与图像先验

传统试衣方案在第二阶段多采用 GAN 网络进行图像融合，往往导致肢体被衣物边缘遮挡处的像素糊成一片，且皮肤与衣领接缝处色差明显。

本项目引入大规模预训练的**扩散修复模型（Diffusion Inpainting Model）**作为图像生成骨干：
- 依靠数十亿图像训练获得的物理光影先验，能够自动推断衣服在锁骨、肩颈处的自然阴影与下垂重力感；
- 完美修复被双手、头发遮挡的部分，重构逼真的身体轮廓。

## 服装 Adapter 模块设计

直接微调整个 Diffusion 模型开销极大且容易遗忘底模常识。因此我们设计了轻量级**服装特征适配器（Garment Adapter）**：

- **解耦交叉注意力（Decoupled Cross-Attention）**：将文本提示词嵌入与服装形变特征向量独立投影，互不干扰；
- **保留局部细节（Detail Retention）**：通过细粒度注意力头将衣服面料的高频材质特征（棉麻、丝绸、牛仔质感）定向注入去噪采样过程；
- **端到端联合训练**：将第一阶段形变网络与第二阶段 Diffusion Adapter 连接，通过联合梯度反向传播实现全局最优，免除了两阶段分别训练带来的误差累积。

## 评测对比与定量指标

在业内通用的 VITON-HD 与 Dress Code 数据集上进行严格对比：
- **SSIM（结构相似性）** 与 **PSNR（峰值信噪比）** 显著超越同期 SOTA 开源基线模型；
- **FID（Frechet Inception Distance）** 大幅降低，说明生成样张在人类视觉感知维度具备更高的逼真度与少伪影特性。
